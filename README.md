# Product Preview Card Component

This is a Product Preview Card Component that I built as part of a Frontend Mentor challenge.

## What I Learned

- How to use HTML to structure a webpage.
- How to use CSS to style a webpage.
- How to use Flexbox to place elements beside each other.
- How `flex-direction: column` can change a layout from horizontal to vertical.
- How to use percentages for widths.
- How to use `object-fit: cover` to control how an image fits inside its container.
- How to use CSS classes to style specific elements.
- How to use HSL colours in CSS.
- How to use Google Fonts.
- How to make a webpage responsive using CSS media queries.
- How to test a website at different screen sizes using browser developer tools.
- How to use browser DevTools to debug CSS by inspecting which rules are being applied to an element.
- How to practice my existing Git and GitHub workflow to save and publish a project.

## Responsive Design

I learned that responsive design means a website can adapt to different screen sizes. For this project:

- Desktop: the image and content appear beside each other.
- Mobile: the image and content stack on top of each other.
- The layout adapts smoothly across screen sizes between mobile and desktop.
